# 🔥 Ritual · Despedida Digna

## 🜂 Cuándo

Cuando un miembro decide salir voluntariamente.

## 🜃 Actividad

1. Escribir carta de salida (opcional)
2. Firmar el acta de despedida
3. Conservar insignias históricas
4. Mantener el hash anclado

## 🜄 Significado

El movimiento no castiga la salida. La firma queda como prueba
de que **existió** y **aportó**.

El hash permanece. Solo el acceso se cierra.
