Manual de Usuario

¿Qué hace este módulo?

Empaqueta todo el ecosistema (identidades, evidencias, eventos, rituales) en un único archivo .legado cifrado con AES-GCM-256 y firmado con Ed25519. Restaurable en cualquier navegador.

¿Cómo exportar?

  • Ejecuta primero los módulos 2.x, 3.x, 4.x y 5.x.
  • Abre cierre/export-cifrado/index.html.
  • Escribe tu contraseña maestra.
  • Toca "Ver inventario" para revisar qué se va a exportar.
  • Toca "Exportar paquete .legado".
  • Guarda el archivo en lugar seguro (disco externo, USB, etc.).

¿Cómo restaurar?

  • Baja a la sección "Restaurar / Verificar".
  • Selecciona el archivo .legado.
  • Elige el modo: verificar, fusionar o reemplazar.
  • Toca "Restaurar paquete".

Manual de Admin

Integración

import { ExportCifrado } from './export.js';

const exp = new ExportCifrado(core, storage);

// Exportar
const { blob, manifiesto } = await exp.exportar(humano);

// Solo manifiesto
const manifiestoBlob = await exp.exportarManifiesto(humano);

// Restaurar
const res = await exp.restaurar(paquete, 'fusionar');
// res: { manifiesto_ok, firma_ok, importados, tipos }

Modos de restauración

  • verificar · solo lee el paquete, no escribe nada.
  • fusionar · añade registros sin borrar los actuales.
  • reemplazar · limpia IndexedDB e importa desde cero.

Estructura del paquete

El archivo .legado contiene: manifiesto (público, firmado) + cipher (datos cifrados) + iv.

Manual de Seguridad

Modelo de amenazas

  • Robo del paquete: los datos están cifrados con AES-GCM-256; sin contraseña no se leen.
  • Manipulación del manifiesto: el manifiesto_hash lo detecta.
  • Suplantación del fundador: la firma Ed25519 lo impide.
  • Sustitución del cipher: el cipher_hash del manifiesto lo detecta.

Parámetros criptográficos

  • AES-GCM-256 con IV de 12 bytes único por exportación.
  • SHA-256 para hash del manifiesto y del cipher.
  • Ed25519 para firma del manifiesto.

Limitaciones honestas

  • Si pierdes la contraseña maestra, el paquete .legado es irrecuperable. No hay backdoor.
  • El paquete NO verifica criptográficamente que el cipher_hash coincida con el cipher real durante la restauración en esta v1.0 (futura mejora).
  • El modo "reemplazar" borra sin confirmación adicional. Úsalo con cuidado.
  • El paquete .legado no incluye las claves privadas Ed25519 ni la clave AES del Cripto Core: solo los datos cifrados. La restauración requiere la misma contraseña maestra en el mismo navegador (o en uno nuevo, donde se derive la misma clave desde la misma contraseña + mismo salt persistido).
  • NO sustituye a un backup profesional: para preservación a décadas, exporta múltiples copias en distintos medios.
