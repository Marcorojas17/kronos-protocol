Manual de Usuario

¿Qué hace este módulo?

Conecta módulos del ecosistema mediante eventos firmados. Cuando un módulo emite un evento, otros pueden reaccionar automáticamente. El log se persiste cifrado y es verificable.

¿Cómo se usa?

  • Ejecuta primero 2.1, 2.2, 2.3, 3.1 y 3.2.
  • Abre orquestacion/event-bus/index.html.
  • Escribe la contraseña maestra.
  • Elige canal, tipo y payload JSON.
  • Toca "Emitir evento".
  • Verifica el log o expórtalo.

Canales disponibles

  • legado:identidad — cambios de identidad.
  • legado:evidencia — evidencias selladas.
  • legado:boveda — audios sellados.
  • legado:gobernanza — cambios de roles.
  • legado:anclaje — anclajes blockchain.

Manual de Admin

Integración

import { EventBus } from './bus.js';

const bus = new EventBus(core, storage);
await bus.init();

// Suscribirse
const off = bus.on('legado:evidencia', (evento) => {
  console.log('Nueva evidencia:', evento.payload);
});

// Emitir
await bus.emit('legado:evidencia', 'evidencia.sellada', {
  id: 'EV-XXXX',
  hash: '0x...'
});

// Verificar
const res = await bus.verificarTodos();

Cross-tab

El bus usa BroadcastChannel. Si abres dos pestañas del mismo origen, los eventos emitidos en una llegan a la otra. Persiste vía Storage Dexie bajo el tipo 'event-bus'.

Manual de Seguridad

Modelo de amenazas

  • Evento alterado: cualquier cambio en el payload rompe el payload_canonico_hash.
  • Falsificación de evento: requiere la clave privada Ed25519 del humano.
  • Suplantación cross-tab: otros orígenes no pueden acceder al BroadcastChannel del ecosistema.

Parámetros criptográficos

  • SHA-256 para hash del payload canónico.
  • Ed25519 para firma del humano.
  • AES-GCM-256 heredado para persistencia cifrada.

Limitaciones honestas

  • BroadcastChannel es por origen: solo funciona dentro del mismo dominio. No sincroniza entre dispositivos sin un backend adicional.
  • El bus no garantiza orden estricto de eventos entre pestañas (los tiempos de red del canal pueden variar milisegundos).
  • No hay reintento automático: si un handler falla, el evento ya quedó persistido pero la reacción no se reintenta.
