# 🔤 Licencias de Fuentes

## 🜂 Fuentes canónicas

| Fuente            | Licencia        | Uso                          |
|-------------------|-----------------|------------------------------|
| JetBrains Mono    | OFL 1.1         | Cuerpo principal · terminal  |
| Fira Code         | OFL 1.1         | Alternativa mono             |
| Inter             | OFL 1.1         | Textos largos · editorial    |
| Courier New       | Sistema         | Fallback universal           |

## 🜃 Descarga

Las fuentes no se incluyen en el repositorio por su tamaño.
El sistema las carga desde CDN (jsDelivr · Google Fonts).

```html
<link rel="preconnect" href="https://fonts.bunny.net">
<link href="https://fonts.bunny.net/css?family=jetbrains-mono:400,700|inter:400,700" rel="stylesheet">
```

## 🜄 Fallback

Si no hay conexión, se usa `Courier New` (sistema).
