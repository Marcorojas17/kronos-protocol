```text
┌─[ 01 ]─────────────────────────────────────────── PROPÓSITO ─┐
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

Esta carpeta existe por tres razones:

```text
  1 · Preservar el proceso creativo completo.
      Incluye versiones fallidas, borradores y experimentos.

  2 · Mantener el repositorio honesto.
      Lo que no es producto va acá, no al frente.

  3 · Servir como referencia histórica.
      Cualquiera puede ver de dónde vino cada idea.
```

Lo que vive acá **no es basura**. Es evidencia de un proceso real.
Pero **no debe confundirse con lo que el proyecto afirma que funciona**.

```text
┌─[ 03 ]─────────────────────── ADVERTENCIAS POR CARPETA ─┐
│                                                           │
└───────────────────────────────────────────────────────────┘
```

**`k4-analysis/`**
Los ejercicios aquí **no resuelven K4**. K4 de Kryptos sigue abierto desde 1990.
Son exploraciones metodológicas, no hallazgos.

**`kronos-2099/`**
Material narrativo especulativo. No representa un sistema operativo real.
Menciona tecnologías y fechas que no existen.

**`embajada-2099/`**
Worldbuilding. Cifras como "127 jurisdicciones" y "2,419 nodos" son ficticias.
No presentar como estado real de ningún sistema.

**`quantum-sovereign/`**
Versión antigua que incluía claims no verificados. Se conserva como
referencia histórica. No usar como fuente técnica.

**`cymatic-v23-v24/`**
Versiones previas de CYMATIC STUDIO con descripciones infladas
("Quantum Neural Forbidden Engine", "IA generativa"). La versión activa
es v19 en `projects/cymatic/`.

**`kronosmv/`**
Proyecto editorial independiente. Se conserva por valor histórico.

```text
┌─[ 05 ]─────────────────────────────────── AUDITORÍA ─┐
│                                                       │
└───────────────────────────────────────────────────────┘
```

Si algo del archive pasa a ser real y verificable:

```text
  1 · Se mueve a projects/ o protocol/
  2 · Se le elimina toda referencia a claims inflados
  3 · Se documenta su estado real (funcional / demo / prototipo)
  4 · Se registra el movimiento en CHANGELOG.md
```

Si algo del archive se descarta definitivamente:

```text
  1 · Se mueve a una subcarpeta legacy/ dentro del propio archive
  2 · Se conserva por valor histórico, sin promoción
  3 · Se registra el descarte en CHANGELOG.md
```
