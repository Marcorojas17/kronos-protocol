## 🔍 ARQUITECTURA · 7 CAPAS LOCAL-FIRST

Diseño **zero-backend**. Toda la criptografía ocurre en el navegador
del usuario. Los datos nunca salen del dispositivo.

| Capa | Nombre | Estado | Descripción |
| :--- | :--- | :---: | :--- |
| **0** | Génesis | ✅ | Documentación fundacional firmada |
| **1** | Cimiento | ✅ | SHA-256 + Ed25519 + AES-GCM + PBKDF2 |
| **2** | Identidad | 🟡 | Registro humano + registro IA |
| **3** | Certificación | ⏳ | Exportación y validación externa |
| **4** | Gobernanza | ⏳ | Votación y propuestas abiertas |
| **5** | Interoperabilidad | ⏳ | APIs con PSC oficiales |
| **6** | Legado Final | 🟡 | Cierre cifrado y exportación digna |

## 🛠️ PRIMITIVAS CRIPTOGRÁFICAS

| Componente | Estándar |
| :--- | :--- |
| Hash de integridad | `SHA-256` (NIST FIPS 180-4) |
| Firma digital | `Ed25519` (RFC 8032) |
| Cifrado simétrico | `AES-GCM-256` (NIST SP 800-38D) |
| Derivación de claves | `PBKDF2` (NIST SP 800-132) |
| Agregación verificable | Merkle Tree (SHA-256) |
| Anclaje público | Ethereum (red por confirmar) |
