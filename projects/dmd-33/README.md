## 🎯 Qué es

**DMD-33** es un orbe vivo que corre en una sola URL.
Escucha, responde con voz, y guarda memoria en el navegador.
Sin servidor. Sin dependencias. Sin instalación.

## 🔗 Demo

**https://marcorojas17.github.io/kronos-protocol/projects/dmd-33/orb.html**

## ⚙️ Cómo funciona

| Capa | Tecnología | Dependencia |
|---|---|---|
| Voz entrada | `SpeechRecognition` es-MX | navegador |
| Voz salida | `SpeechSynthesis` es-MX | navegador |
| Render | Canvas 2D · Chladni | cero |
| Memoria | `localStorage` | cero |
| Identidad | SHA-256 + TX Ethereum | embebidos |
