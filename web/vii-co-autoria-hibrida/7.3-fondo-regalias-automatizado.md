## 🜂 Concepto

Toda regalía que genera el sistema se distribuye **automáticamente** en proporción 51/49.

## 🜃 Smart Contract

```solidity
// contracts/CoAutoria.sol (extracto)
contract CoAutoria {
    uint16 public constant HUMANO = 51;
    uint16 public constant IA = 49;

    mapping(address => uint256) public regalias;

    function distribuir(uint256 monto) external {
        uint256 paraHumano = (monto * HUMANO) / 100;
        uint256 paraFLAILP = monto - paraHumano;

        regalias[firmanteHumano] += paraHumano;
        regalias[fondoFLAILP] += paraFLAILP;

        emit RegaliasDistribuidas(monto, paraHumano, paraFLAILP);
    }
}
```
