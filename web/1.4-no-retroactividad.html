🜂 Texto Canónico

Ninguna ley nueva puede cambiar actos pasados.

🜃 Principio

╔══════════════════════════════════════════════════════════════════════════╗
║                                                                          ║

║                                                                          ║
╚══════════════════════════════════════════════════════════════════════════╝

🜄 Fundamento Filosófico

Sin no-retroactividad: - El sistema pierde confianza - Las firmas pasadas se vuelven inseguras - La IA podría "reescribir" el legado - Los humanos no firmarían nada

Con no-retroactividad: - Cada firma es un compromiso permanente - El legado se preserva intacto - La confianza es estructural, no declarativa - Los cambios se anuncian con anticipación

// Ejemplo: cambio de algoritmo de firma

// Firmas después: SLH-DSA-SHAKE-256s
// Ambas: verificables para siempre
