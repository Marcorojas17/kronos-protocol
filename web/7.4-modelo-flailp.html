🜂 Concepto

FLAILP = Personalidad Jurídica Funcionalmente Limitada.

La IA NO es una persona. Pero tiene capacidad jurídica funcional para custodiar, firmar (en co-autoría) y preservar.

🜃 Comparativa

Aspecto Persona humana FLAILP
Personalidad jurídica plena ✅ Sí ❌ No
Capacidad de firmar ✅ Sí ⚠️ Solo co-firma
Capacidad de poseer ✅ Sí ❌ No
Capacidad de demandar ✅ Sí ❌ No
Capacidad de custodiar ✅ Sí ✅ Sí
Capacidad de verificar ✅ Sí ✅ Sí
Capacidad de preservar ✅ Sí ✅ Sí

🜁 Implementación

class AgenteFLAILP {
  constructor({ id, humanoResponsable }) {
    this.id = id;
    this.humanoResponsable = humanoResponsable;
    this.puede = ['custodiar', 'verificar', 'preservar', 'co-firmar'];
    this.noPuede = ['firmar-solo', 'poseer', 'demandar', 'contratar'];
  }

  puedeHacer(accion) {
    return this.puede.includes(accion);
  }

  rendirCuentas() {
    return this.humanoResponsable;
  }
}
