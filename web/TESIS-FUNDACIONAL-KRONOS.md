La gobernanza del sistema no es democrática ni autocrática. Es **simbiótica**:


## 🔐 CAPÍTULO IV · FUNDAMENTOS CRIPTOGRÁFICOS

### 4.1 · Criptografía Post-Cuántica

La computación cuántica amenaza los algoritmos criptográficos clásicos (RSA, ECC). KRONOS implementa **criptografía resistente a ataques cuánticos**:

```
┌──────────────────────────────────────────────────────────────────┐
│  ALGORITMO      │  TIPO            │  USO EN KRONOS              │
├─────────────────┼──────────────────┼─────────────────────────────┤
│  ML-KEM (Kyber) │  Key Encapsulation│  Cifrado de claves         │
│  ML-DSA (Dilithium)│ Firmas digitales│ Firmas de autoría         │
│  SLH-DSA (SPHINCS+)│ Firmas hash-based│ Firmas de largo plazo    │
│  SHA-256        │  Hash            │  Integridad de archivos     │
│  BLAKE3         │  Hash rápido     │  Verificación en tiempo real│
│  AES-256-GCM    │  Cifrado simétrico│ Cifrado de datos sensibles │
└─────────────────┴──────────────────┴─────────────────────────────┘
```

**Enfoque híbrido:** KRONOS combina algoritmos clásicos y post-cuánticos en paralelo. Si uno falla, el otro protege.

### 4.2 · Cadena de Custodia NOM-151

Cada obra certificada en KRONOS pasa por:

1. **Recepción** · Timestamp de ingreso (RFC 3161)
2. **Hash** · SHA-256 del archivo original
3. **Firma** · Firma digital del perito (ML-DSA)
4. **Anclaje** · Transacción en Polygon Amoy
5. **Log** · Registro inmutable en Arweave
6. **Certificado** · PDF con sello y firma criptográfica

**Estándares cumplidos:**

- NOM-151-SCFI-2016 (México)
- ISO 27037:2012 (Forensia digital)
- eIDAS (Unión Europea)
- RFC 3161 (Timestamp)
- ISO 27001:2022 (Seguridad)
