🜂 Contexto

¿Cómo diferenciar visualmente las páginas sin perder consistencia?

🜃 Decisión

Temas por página con CSS custom properties: - terminal-amber (default · hub) - terminal-gold (KINTSUGI · manifiesto) - terminal-green (verificar · éxito) - terminal-cyan (firmar · nuevo) - terminal-red (404 · HALT)

🜄 Implementación

<body data-page="verificar" data-theme="terminal-green">

[data-theme="terminal-green"] {
  --accent: #00ff9f;
  --accent-2: #00d4ff;
}

🜁 Alternativas

  1. Un solo tema · Rechazada (monótono)
  2. Temas aleatorios · Rechazada (confuso)
  3. Temas por página · ✅ Aceptada
