Manual de Usuario

¿Qué hace este módulo?

Permite crear propuestas firmadas criptográficamente y votar en ellas. Cada voto es firmado con Ed25519. Los resultados se calculan localmente. Sin servidor, sin censura, sin manipulación.

¿Cómo crear una propuesta?

  1. Escribe tu contraseña maestra.
  2. Selecciona tu rol.
  3. Toca "Crear nueva propuesta".
  4. Llena el título, descripción, tipo, opciones de voto y duración.
  5. Toca "Firmar y publicar propuesta".
  6. Recibirás un ID de propuesta (formato PROP-XXXXXXXX).

¿Cómo votar?

  1. Toca "Ver propuestas abiertas".
  2. Selecciona la propuesta que quieras.
  3. Marca la opción de tu preferencia.
  4. Toca "Firmar voto".
  5. Tu voto queda registrado y firmado. No puedes votar dos veces.

¿Qué puedo verificar?

  • La firma Ed25519 de cualquier propuesta (botón "Verificar firma").
  • Los resultados en tiempo real de cualquier propuesta.
  • El total de votos y porcentajes por opción.

Manual de Admin

Integración

import { CriptoCore } from '../../cimiento/cripto-core/core.js';
import { Propuestas } from './propuestas.js';
import { Votacion } from './votacion.js';

const core = new CriptoCore();
await core.init(password);

const propuestas = new Propuestas(core);
await propuestas.init();

const p = await propuestas.crear({
  titulo: 'Adoptar NOM-151-SCFI-2016',
  descripcion: 'Propongo adoptar el estándar mexicano de sellado...',
  tipo: 'Cambio estructural',
  opciones: ['A favor', 'En contra', 'Abstención'],
  autor_hash: core.clavePublicaHex,
  autor_nombre: 'Marco Antonio Rojas Valdovinos',
  autor_rol: 'Fundador',
  duracion_dias: 7
});

const votacion = new Votacion(core);
await votacion.init();
await votacion.votar({
  id_propuesta: p.id_propuesta,
  opcion_elegida: 'A favor',
  votante_hash: core.clavePublicaHex,
  votante_nombre: 'Marco Antonio Rojas Valdovinos',
  votante_rol: 'Fundador'
});

const res = await votacion.resultados(p.id_propuesta, p.opciones);
// res.total_votos, res.conteo, res.ganadora

Manual de Seguridad

Modelo de confianza

  • Cada propuesta y cada voto son firmados con Ed25519.
  • El hash del payload detecta cualquier alteración posterior.
  • Una identidad no puede votar dos veces en la misma propuesta.
  • Los resultados se calculan localmente, sin servidor intermediario.

Limitaciones honestas

  • En v1.0, todos los votos se firman con la llave del fundador (no hay multi-firma real).
  • La resistencia Sybil (una persona = un voto) requiere integración con el Registro Humano.
  • No hay registro inmutable externo todavía. Los votos viven en Dexie local.
  • La verificación de "un humano real por voto" aún no está implementada.

Roadmap

  • v1.1: Firma con la llave de cada votante registrado.
  • v1.2: Anclaje del resultado final a Ethereum.
  • v1.3: Integración con Registro Humano para anti-Sybil.
