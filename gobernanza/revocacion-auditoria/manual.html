Manual de Usuario

¿Qué hace este módulo?

Permite revocar roles de forma firmada y auditable, y genera un reporte completo del estado del ecosistema de gobernanza (propuestas, votos, actas, revocaciones).

¿Cómo revocar un rol?

  1. Escribe tu contraseña maestra.
  2. Pega el hash de la identidad a revocar.
  3. Escribe su nombre y tipo.
  4. Selecciona el rol a revocar.
  5. Escribe el motivo (mín. 10 caracteres).
  6. Toca "Revocar rol y firmar".
  7. Recibirás un ID de revocación (formato REV-XXXXXXXX).

¿Cómo auditar el ecosistema?

  1. Escribe tu contraseña maestra.
  2. Toca "Auditar ecosistema completo".
  3. Verás un resumen de propuestas, votos, actas y revocaciones.
  4. Puedes exportar el reporte como JSON.

Nota importante

Las revocaciones no borran nada. Solo marcan el rol como revocado. El histórico queda intacto para auditoría.

Manual de Admin

Integración

import { RevocacionAuditoria } from './revocacion.js';

const rev = new RevocacionAuditoria(core, propuestas, votacion, ejecucion);
await rev.init();

const r = await rev.revocarRol({
  identidad_hash: 'abc123...',
  identidad_nombre: 'Colaborador XYZ',
  identidad_tipo: 'humano',
  rol_revocado: 'Colaborador',
  motivo: 'Incumplimiento reiterado de la política'
});

const auditoria = await rev.auditar();
// auditoria.propuestas.total, auditoria.votos.total, etc.

Manual de Seguridad

Modelo de confianza

  • Cada revocación es firmada con Ed25519 por el fundador.
  • El hash del payload detecta cualquier alteración posterior.
  • Nada se borra: todo se marca como activo o levantado.
  • El reporte de auditoría es reproducible y verificable.

Limitaciones honestas

  • La revocación es declarativa: no elimina el rol de la identidad en otros módulos.
  • El chequeo de revocaciones en tiempo real requiere integración con roles-permisos.
  • En v1.0 todo se firma con la llave del fundador.
  • El anclaje de revocaciones a Ethereum es opcional y está pendiente.
