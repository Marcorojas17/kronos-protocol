Manual de Usuario

¿Qué hace este módulo?

Cierra propuestas abiertas y emite un acta oficial firmada con el veredicto final. El acta registra cuántos votos hubo, qué opción ganó, si se alcanzó quórum y mayoría, y la acción ejecutada.

¿Cómo se usa?

  1. Escribe tu contraseña maestra.
  2. Indica cuántos ciudadanos activos hay.
  3. Toca "Ver propuestas abiertas".
  4. Selecciona la propuesta que quieras cerrar.
  5. Verás un veredicto anticipado (aprobada/rechazada/sin quórum).
  6. Escribe la acción ejecutada (opcional).
  7. Toca "Firmar acta y cerrar".
  8. Se emite el acta firmada y se registra.

¿Qué obtengo?

  • Un acta con ID único (formato ACTA-XXXXXXXX).
  • Firma Ed25519 verificable.
  • Hash del payload auditable.
  • Posibilidad de exportarlo como JSON.

Manual de Admin

Integración

import { EjecucionDecisiones } from './ejecucion.js';

const ejecucion = new EjecucionDecisiones(core, propuestas, votacion, quorum);
await ejecucion.init();

const acta = await ejecucion.cerrar({
  propuesta: propuestaObj,
  ciudadanos_activos: 100,
  accion_ejecutada: 'Actualizar versión del protocolo'
});

// acta.veredicto → 'aprobada' | 'rechazada' | 'sin_quorum'
// acta.id_acta → 'ACTA-XXXXXXXX'
// acta.firma_ed25519 → firma verificable

Manual de Seguridad

Modelo de confianza

  • Cada acta es firmada con Ed25519 por el fundador.
  • El hash del payload detecta cualquier alteración posterior.
  • La verificación no requiere contraseña (solo claves públicas).

Limitaciones honestas

  • La "acción ejecutada" es declarativa: no se aplica automáticamente al código del protocolo.
  • El acta prueba la decisión, no la implementación técnica del cambio.
  • En v1.0 todo se firma con la llave del fundador.
  • El anclaje del acta a Ethereum es opcional (pendiente para v1.1).
