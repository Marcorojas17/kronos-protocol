Manual de Usuario

¿Qué hace este módulo?

Define cuántos votos se necesitan para aprobar cada tipo de propuesta. No todas las decisiones requieren el mismo consenso: un typo necesita menos que un cambio criptográfico.

Reglas por tipo

  • Cambio menor: quórum 20%, mayoría simple.
  • Cambio estructural: quórum 50%, mayoría absoluta.
  • Cambio criptográfico: quórum 66%, mayoría calificada.
  • Adopción: quórum 50%, mayoría absoluta.
  • Recurso: quórum 33%, mayoría simple.

¿Cómo se usa el simulador?

  1. Elige el tipo de propuesta.
  2. Ingresa cuántos ciudadanos activos hay.
  3. Ingresa cuántos votos se emitieron.
  4. Ingresa cuántos votos obtuvo la opción ganadora.
  5. Toca "Calcular veredicto".
  6. Verás si la propuesta sería aprobada, rechazada o sin quórum.

Manual de Admin

Integración

import { QuorumMayorias } from './quorum.js';

const q = new QuorumMayorias();

const v = q.veredicto(
  { total_votos: 60, conteo: { 'Sí': 40 }, ganadora: 'Sí' },
  100,  // ciudadanos activos
  'Cambio estructural',
  'cerrada'
);

// v.verdicto → 'aprobada' | 'rechazada' | 'sin_quorum'
// v.razon → explicación

Modificar las reglas

Las reglas están declaradas en el constructor de quorum.js. Si el protocolo adopta umbrales distintos, se edita ahí y se hace commit.

Manual de Seguridad

Modelo de confianza

  • Los umbrales están declarados y son auditables.
  • El cálculo es determinista y reproducible.
  • El hash de las reglas puede anclarse on-chain.

Limitaciones honestas

  • El conteo de ciudadanos activos aún es manual en v1.0.
  • No hay verificación criptográfica de que cada voto venga de un humano distinto.
  • Los umbrales son orientativos; el protocolo puede ajustarlos.
