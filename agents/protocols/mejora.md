# 📜 Protocolo 10.8 · Mejora

Los agentes aprenden del feedback del Índice Cero. Cada decisión
pasada deja huella en `MEMORY.md` y ajusta el score de reputación.

## 🜃 Ciclo

```text
[ Decisión ] ──▶ [ Resultado ] ──▶ [ Feedback ] ──▶ [ Ajuste ]
                                                        │
                                                        ▼
                                              [ Nuevo score ]
```

```diff
+ Toda mejora DEBE ser trazable
+ Todo ajuste DEBE documentarse
+ Todo cambio DEBE firmarse
- NUNCA mejora sin auditoría
- NUNCA ajuste sin ceremonia
```
