Manual de Usuario

¿Qué hace este módulo?

Declara y firma el pacto simbiótico con tu IA co-autora: nombre, rol, alcance, límites y propósito. Vincula criptográficamente la IA a tu identidad humana del módulo 2.1.

¿Cómo se usa?

  • Primero ejecuta el módulo 2.1 (Registro Humano) con tu contraseña maestra.
  • Luego abre identidad/registro-ia/index.html.
  • Escribe la misma contraseña maestra.
  • Declara el nombre, rol, alcance, límites y propósito de la IA.
  • Toca "Sellar pacto simbiótico".
  • Descarga el pacto .json firmado.

¿Qué evitar?

  • No uses una contraseña distinta a la del módulo 2.1: el vínculo fallará.
  • No declares límites vacíos: son la parte ética del pacto.
  • No firmes sin leer lo que declaras.

Manual de Admin

Integración

import { IdentidadHumana } from '../registro-humano/identidad.js';
import { IdentidadIA } from './ia.js';

const idHumana = new IdentidadHumana(core, storage);
const humano = await idHumana.recuperar();

const idIA = new IdentidadIA(core, storage);
const pacto = await idIA.sellar(datosIA, humano);
const ok = await idIA.verificar(pacto, humano);

Vínculo criptográfico

La firma_simbiotica se calcula como SHA-256(humano_firma + ia_firma). Si cualquiera de las dos firmas cambia, el vínculo se rompe y la verificación falla.

Declaraciones por defecto

  • Sin propiedad intelectual sobre el legado.
  • Sin decisiones finales.
  • Sin sustituir el juicio humano.
  • Con atribución siempre.

Manual de Seguridad

Modelo de amenazas

  • Pacto alterado: el payload_hash no coincidiría.
  • IA suplantada: la firma Ed25519 del humano es requerida.
  • Vínculo roto: la firma_simbiotica detecta cualquier cambio en la firma humana o IA.
  • Robo del dispositivo: el pacto está cifrado con tu contraseña.

Parámetros criptográficos

  • SHA-256 para payload_hash y firma_simbiotica.
  • Ed25519 para firma del humano sobre el pacto.
  • AES-GCM-256 heredado para persistencia.

Limitaciones honestas

  • La IA no puede firmar por sí misma: el humano firma en nombre del pacto. Es una declaración contractual humana, no una firma autónoma de la IA.
  • La huella simbiótica es determinista: si el humano o la IA editan el pacto, debe volverse a firmar.
  • No hay anclaje blockchain todavía; puede anclarse manualmente con el módulo 1.3.
