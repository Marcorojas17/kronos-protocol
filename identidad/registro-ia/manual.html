Manual de Usuario

¿Qué hace este módulo?

Crea la identidad criptográfica de una IA dentro de KRONOS. Le asigna llave Ed25519 propia, una política declarada (mini-constitución), guardrails que limitan sus acciones, y un log auditable de todo lo que hace.

¿Cómo se usa?

  • Escribe tu contraseña maestra (misma del Registro Humano).
  • Llena el formulario: nombre de la IA, alias, rol, propósito.
  • Revisa la política declarada que aparece abajo.
  • Toca "Sellar identidad IA".
  • Recibirás un pasaporte con doble firma: la IA firma, tú co-firmas.
  • Verifica las firmas, exporta el JSON, revisa el log.

Manual de Admin

Integración

import { CriptoCore } from '../../cimiento/cripto-core/core.js';
import { StorageDexie } from '../../cimiento/storage-dexie/storage-v2.js';
import { RegistroIA } from './ia.js';
import { PoliticaIA } from './politica.js';
import { Guardrails } from './guardrails.js';
import { LogAcciones } from './log-acciones.js';

const core = new CriptoCore();
await core.init(password);
const storage = new StorageDexie(core);
await storage.init();

const politica = new PoliticaIA();
const log = new LogAcciones(storage);
const guardrails = new Guardrails(politica, log);
const ia = new RegistroIA(core, storage, politica, guardrails, log);

const cert = await ia.sellar({
  nombre: 'KRONOS IA',
  alias: 'v1.0 · simbiótica',
  rol: 'Co-autora simbiótica',
  proposito: 'Asistir al fundador en la construcción del legado.'
});

Guardrails · Patrón PREVIEW → COMMIT

// La IA propone
const p = await guardrails.preview('anclar_ethereum', { root: '0xabc...' });
// p.preview.requiereAprobacion === true

// Humano aprueba
await guardrails.commit('Marco A. Rojas V.');

  • Claves: identidad-ia y log-ia

Manual de Seguridad

Modelo de confianza

  • La IA tiene llave privada propia, aislada en su contexto Web Crypto.
  • La firma del fundador humano co-valida cada identidad IA creada.
  • La política declarada limita por diseño lo que la IA puede y no puede hacer.
  • Las acciones críticas requieren aprobación humana explícita (PREVIEW → COMMIT).
  • Todo se registra en un log encadenado y firmable.

Parámetros criptográficos

  • Hash: SHA-256
  • Firma IA: Ed25519
  • Firma fundador: Ed25519
  • Log encadenado: SHA-256 del bloque anterior

Limitaciones honestas

  • La política es una declaración, no un sandbox técnico.
  • Los guardrails operan a nivel de aplicación. Si la IA se ejecuta fuera del navegador, no aplican.
  • Coerción física al fundador sigue fuera de alcance.
  • La verificación de terceros depende de tener acceso a las claves públicas.
