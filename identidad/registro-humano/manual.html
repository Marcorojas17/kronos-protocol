Manual de Usuario

¿Qué hace este módulo?

Crea tu identidad firmada con Ed25519, genera una huella criptográfica única de 64 caracteres y emite un pasaporte digital verificable.

¿Cómo se usa?

  • Abre identidad/registro-humano/index.html.
  • Escribe la contraseña maestra (mínimo 8 caracteres).
  • Llena alias, nombre, país, rol y propósito.
  • Toca "Sellar identidad".
  • Descarga tu pasaporte .json o copia la huella.

¿Qué evitar?

  • No pierdas la contraseña maestra: sin ella, no podrás recuperar el perfil cifrado.
  • No compartas la huella con propósitos sensibles (es pública si la exportas).
  • No declares datos falsos: el propósito es firmar identidad real.

Manual de Admin

Integración

import { CriptoCore } from '../../cimiento/cripto-core/core.js';
import { StorageDexie } from '../../cimiento/storage-dexie/storage.js';
import { IdentidadHumana } from './identidad.js';

const core = new CriptoCore();
await core.init(password);
const storage = new StorageDexie(core);
await storage.init();

const identidad = new IdentidadHumana(core, storage);
const cert = await identidad.sellar(datos);
const perfil = await identidad.recuperar();
const ok = await identidad.verificar(cert);

Persistencia

Los certificados se guardan cifrados con Cripto Core y se indexan en Storage Dexie bajo el tipo 'identidad-humana'.

Backup

Toca "Descargar pasaporte .json" en la demo. El archivo contiene el certificado completo + firma Ed25519 verificable.

Manual de Seguridad

Modelo de amenazas

  • Suplantación: la firma Ed25519 es infalsificable sin la clave privada.
  • Alteración de datos: cualquier cambio rompe el payload_hash.
  • Robo del dispositivo: los datos están cifrados con tu contraseña maestra.
  • MITM: no hay red, todo local.

Parámetros criptográficos

  • SHA-256 para hash del payload + huella.
  • Ed25519 para firma digital del hash.
  • AES-GCM-256 heredado del Cripto Core para persistencia.
  • Huella = SHA-256(clave_pública + payload_hash) · 64 caracteres.

Limitaciones honestas

  • La huella es pseudónima: revela un identificador estable, no datos personales. Compártela con criterio.
  • Sin anclaje en blockchain todavía; el módulo 1.3 permite anclarla manualmente.
  • No hay borrado criptográfico remoto: si pierdes la contraseña, el perfil queda inaccesible.
