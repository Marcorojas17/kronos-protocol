Manual de Usuario

¿Qué hace Tonal?

Tonal emite sellos notariales criptográficos que prueban la existencia y la fecha de cualquier información. Cada sello lleva:

  • Hash SHA-256 del contenido
  • Timestamp ISO 8601 + Unix
  • Firma Ed25519 del notario
  • Opcional anclaje a Ethereum Mainnet

¿Cómo sellar?

  1. Escribe tu contraseña maestra
  2. Pega el texto o hash que quieres sellar
  3. Elige tipo de documento
  4. Escribe tu nombre como solicitante
  5. Toca "Emitir sello notarial"
  6. Opcional: toca "Anclar a Ethereum" para prueba pública
  7. Descarga el certificado notarial visual

Manual de Admin

Integración

import { NotarioKronos } from './notario.js';

const notario = new NotarioKronos(core);
await notario.init();

const sello = await notario.sellar({
  hash_sellado: 'abc123...',
  tipo_documento: 'Contrato',
  descripcion: 'Contrato de servicios',
  solicitante: 'Marco A. Rojas V.',
  incluir_anclaje_ethereum: true
});

const v = await notario.verificar(sello);
// v.valido === true si hash y firma coinciden

Manual de Seguridad

Modelo de confianza

  • Hash SHA-256 del contenido
  • Firma Ed25519 del notario
  • Log encadenado del notario
  • Anclaje opcional a Ethereum Mainnet

Límites honestos

  • Tonal NO es una TSA cualificada eIDAS.
  • NO sustituye a una firma electrónica cualificada europea.
  • NO tiene acreditación de ENAC ni equivalente.
  • PERO sí es verificable criptográficamente y anclable a Ethereum.
  • Es un notario criptográfico soberano, no un notario jurídico.
