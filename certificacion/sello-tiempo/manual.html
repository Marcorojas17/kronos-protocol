Manual de Usuario

¿Qué hace este módulo?

Genera una solicitud de sello de tiempo (TimeStampQuery, RFC 3161) que puede ser enviada a una Autoridad de Sellado de Tiempo (TSA) para obtener una prueba criptográfica de que tu información existía en una fecha específica.

Flujo de uso

  1. Ingresa un texto o sube un archivo.
  2. Calcula el hash SHA-256.
  3. Genera el archivo .tsq.
  4. Descarga el .tsq.
  5. Ve a freetsa.org/tsr y sube el .tsq.
  6. Descarga el .tsr que genera Freetsa.
  7. Vuelve a KRONOS y sube el .tsr para procesarlo.
  8. Guarda el .tsr como prueba. Contiene la firma de tiempo.

¿Qué obtengo?

Un archivo .tsr firmado por la TSA. Cualquier persona puede verificar con herramientas especializadas (openssl ts -verify) que ese sello fue emitido por la TSA en esa fecha exacta.

TSAs gratuitas compatibles

  • Freetsa — freetsa.org/tsr (gratuita, sin registro)
  • DigiCert — solo para clientes comerciales
  • Firmaprofesional — para España / cualificada eIDAS

Manual de Seguridad

Modelo de confianza

  • El sello es emitido por una TSA reconocida internacionalmente.
  • La TSA firma el hash + timestamp con su propia clave.
  • La prueba criptográfica es independiente de KRONOS.
  • KRONOS solo genera la solicitud y muestra la fecha extraída.

Limitaciones honestas

  • Este cliente NO verifica criptográficamente el sello TSR. Solo extrae la fecha heurísticamente y confirma que tiene estructura ASN.1.
  • La verificación completa requiere openssl ts -verify o equivalente.
  • Freetsa es gratuito pero NO es una TSA cualificada eIDAS.
  • Para validez legal plena en la UE, se requiere una TSA cualificada (Firmaprofesional, FNMT).
  • El sello prueba que el hash existía en esa fecha. No prueba quién lo creó.

Verificación externa recomendada

# Con el .tsq original y el .tsr recibido
openssl ts -verify -in sello.tsr -queryfile solicitud.tsq \
  -CAfile tsa-certs.pem -untrusted tsa-chain.pem
