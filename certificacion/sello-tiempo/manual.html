Manual de Usuario

¿Qué hace este módulo?

Genera una solicitud de sello de tiempo (TimeStampQuery, RFC 3161) que puede ser enviada a una Autoridad de Sellado de Tiempo (TSA) para obtener una prueba criptográfica de existencia temporal.

⚠️ Cambio importante: Freetsa.org dejó de funcionar (403 Forbidden desde septiembre 2026). Se usan las siguientes TSA alternativas oficiales.

¿Cómo sellar?

  1. Escribe o sube el contenido a sellar.
  2. Calcula el hash SHA-256.
  3. Genera el archivo .tsq.
  4. Descarga el .tsq.
  5. Envía el .tsq a una TSA activa (por ejemplo, vía el cliente DigiCert Timestamp Client o el servicio online de Sectigo).
  6. Descarga el .tsr resultante.
  7. Vuelve a KRONOS y sube el .tsr para procesarlo.

Alternativa sin TSA: Notario Tonal

KRONOS incluye un notario criptográfico propio (agente Tonal, Plaza IA 086) que emite sellos firmados con Ed25519 y anclables a Ethereum. Sin depender de TSA externa. Ver Notario Tonal →

Manual de Seguridad

Modelo de confianza

  • El sello es emitido por una TSA reconocida internacionalmente.
  • La TSA firma el hash + timestamp con su propia clave.
  • La prueba criptográfica es independiente de KRONOS.
  • KRONOS solo genera la solicitud y muestra la fecha extraída.

Limitaciones honestas

  • Este cliente NO verifica criptográficamente el sello TSR. Solo extrae la fecha heurísticamente.
  • La verificación completa requiere openssl ts -verify o equivalente.
  • Las TSA gratuitas NO son cualificadas eIDAS.
  • Para validez legal plena en la UE se requiere TSA cualificada (Firmaprofesional, FNMT).
  • Alternativa recomendada: usar el Notario Tonal propio + anclaje a Ethereum, que sí es verificable sin depender de TSA externa.
