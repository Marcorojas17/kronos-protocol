Manual de Usuario

¿Qué hace este módulo?

Emite certificados oficiales que combinan hash del contenido + firma Ed25519 + sello de tiempo opcional. Cada certificado es verificable por cualquier tercero con las claves públicas.

¿Cómo se usa?

  1. Escribe tu contraseña maestra.
  2. Selecciona tipo de documento, título, destinatario.
  3. Pega el contenido a certificar.
  4. Toca "Emitir certificado".
  5. Puedes verificarlo, exportarlo como JSON, o generar un certificado visual (PNG/PDF).

Manual de Admin

Integración

import { EmisorCertificados } from './certificados.js';

const emisor = new EmisorCertificados(core, storage, sello);
await emisor.init();

const cert = await emisor.emitir({
  tipo_documento: 'Contrato',
  titulo: 'Contrato de servicios',
  destinatario: 'Empresa XYZ S.A.',
  contenido: 'Texto completo del contrato...',
  tsa_info: null
});

const v = await emisor.verificar(cert);
// v.valido === true

Manual de Seguridad

Modelo de confianza

  • El hash del contenido detecta cualquier alteración posterior.
  • La firma Ed25519 prueba autoría del fundador.
  • El sello de tiempo RFC 3161 (opcional) prueba cuándo existió.
  • Cualquiera con la clave pública del fundador puede verificar.

Limitaciones honestas

  • Este certificado NO sustituye a un documento notarial.
  • La validez legal plena requiere integración con PSC oficiales.
  • El sello de tiempo es opcional; sin él, no hay prueba cualificada de cuándo se emitió.
  • La firma es válida, pero no hay cadena de certificación PKI/x509 completa.
