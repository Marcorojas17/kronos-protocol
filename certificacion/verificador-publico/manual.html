Manual de Usuario

¿Qué hace este módulo?

Permite a cualquiera verificar que los archivos de KRONOS no han sido alterados. Se compara el hash SHA-256 de cada archivo subido contra el hash registrado en el manifest oficial.

¿Cómo se usa?

  • Descarga el manifest.json del repositorio de KRONOS.
  • Copia su contenido y pégalo en el área de texto.
  • Toca "Cargar manifest".
  • El sistema verifica automáticamente si el manifest es íntegro.
  • Sube los archivos que quieras verificar (descargados del repo).
  • Toca "Verificar archivos".
  • Verás el estado de cada archivo: verificado, alterado o desconocido.

¿Qué significa cada resultado?

  • ✓ Verificado: El archivo coincide con el hash del manifest. No fue alterado.
  • ✗ Alterado: El archivo NO coincide con el manifest. Fue modificado.
  • ? Desconocido: El archivo no está registrado en el manifest.

Manual de Admin

Integración

import { VerificadorManifest } from './verificador.js';

const verif = new VerificadorManifest();
verif.cargarManifest(jsonString);

const resumen = await verif.verificarVarios(files);
// resumen.ok === true si todo está verificado

const integridad = await verif.verificarHashRaiz();
// integridad.ok === true si el manifest no fue alterado

Cuándo usar este módulo

  • Antes de presentar KRONOS ante una institución.
  • Después de clonar el repo, para confirmar que nada cambió.
  • Como parte de una auditoría técnica externa.
  • En el flujo de verificación de certificados emitidos por KRONOS.

Manual de Seguridad

Modelo de confianza

  • El manifest contiene los hashes SHA-256 de cada archivo.
  • Si un archivo es alterado, su hash cambia por completo.
  • El hash_raiz del manifest es el hash del conjunto, no de un archivo individual.
  • Cualquier alteración del manifest es detectable recalculando su hash raíz.

Limitaciones honestas

  • Este verificador no sustituye a un sello de tiempo cualificado (RFC 3161).
  • Si alguien altera tanto el archivo como el manifest, la verificación pasaría. Eso se resuelve con el Módulo 3.3 (Sellado de Tiempo).
  • La confianza última depende de que el manifest original esté en un lugar público verificable (GitHub + Ethereum).
