Manual de Usuario

¿Qué hace este módulo?

Publica el hash raíz del manifest en Ethereum Mainnet. Eso crea una prueba pública y permanente de que tus archivos existían en esa fecha exacta.

¿Cómo se usa?

  1. Pega el manifest generado en el Módulo 3.1.
  2. Toca "Cargar manifest".
  3. Escribe tu contraseña maestra.
  4. Conecta MetaMask en Ethereum Mainnet.
  5. Toca "Anclar a Ethereum Mainnet".
  6. Confirma la transacción en MetaMask (cuesta centavos de gas).
  7. Recibirás el TX Hash. Guárdalo como prueba.

¿Qué obtengo?

Una transacción en Ethereum Mainnet que contiene el hash raíz del manifest. Cualquiera puede consultarla en Etherscan y verificar que ese hash existía en esa fecha.

Nota honesta

MetaMask no está disponible en todos los navegadores móviles. Si estás en Chrome/Brave, necesitas abrir la página dentro del navegador interno de la app MetaMask.

Manual de Admin

Integración

import { AnclajeManifest } from './anclaje.js';

const anclaje = new AnclajeManifest(core);
const r = anclaje.cargarManifest(jsonString);
// r.hash_raiz → 0x...

const resultado = await anclaje.anclarConMetaMask();
// resultado.tx_hash → 0x...
// resultado.etherscan_url → https://etherscan.io/tx/0x...

Cuándo usarlo

  • Cada vez que hagas un release importante del protocolo.
  • Cuando quieras probar la integridad pública de tu repo.
  • Como parte del cierre anual del proyecto.

Manual de Seguridad

Modelo de confianza

  • El hash raíz del manifest se envía en el campo data de la TX.
  • La TX se firma con tu wallet y se publica en Ethereum Mainnet.
  • Cualquiera puede verificar la TX en Etherscan.
  • El valor es 0 ETH: solo se publica la prueba, no se mueve dinero.

Limitaciones honestas

  • Anclar cuesta gas real (~0.0001-0.001 ETH según congestión).
  • No hay forma de borrar la TX una vez publicada.
  • El anclaje prueba existencia, no autoría. Para autoría, la firma Ed25519 del manifest ya lo hace.
  • MetaMask no está disponible en Brave/Chrome móvil sin la app.
