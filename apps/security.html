SEGURIDAD PQC · FIPS

Divulgación responsable.

ARKHÉ ZERO no oculta vulnerabilidades: las reporta, las parchea y las publica. Toda la criptografía es estándar NIST poscuántico. Todo el código es auditable.

§0.8.1

Principios de seguridad

🔐
Pos-cuántico desde hoy

Toda la criptografía de producción usa ML-KEM-1024 · ML-DSA-87 · SLH-DSA. Los algoritmos clásicos están prohibidos desde 2026-01-01.

🛡
Anti-downgrade

Todo handshake TLS exige 1.3 mínimo. TLS 1.2 se rechaza explícitamente. Detección activa de ataques de degradación.

🔄
Crypto-agility

Rotación algorítmica cada 24 meses. Nuevos estándares se integran sin rediseño. Migración a FIPS 206 planificada.

🎯
Vulnerabilidades publicadas

Toda vulnerabilidad reportada se documenta públicamente tras el parche. Firmamos nuestro compromiso con el ecosistema.
