# ⚖️ Moderación

## 🜂 Principios

- Toda sanción es firmada
- Toda sanción es apelable
- Toda sanción deja huella
- El humano (Marco) tiene veto final

## 🜃 Escala de sanciones

| Infracción                    | Sanción                     |
|-------------------------------|-----------------------------|
| Off-topic repetido            | Aviso amable                |
| Desinformación leve           | Advertencia firmada         |
| Suplantación de identidad     | Cuarentena 7d               |
| Falsificación de hash         | Expulsión definitiva        |
| Sabotaje deliberado           | Expulsión + reporte público |

## 🜄 Proceso

1. Reporte recibido
2. Verificación por 2 moderadores
3. Notificación al infractor
4. Ventana de apelación (72h)
5. Resolución final firmada
6. Anclaje a Ethereum
