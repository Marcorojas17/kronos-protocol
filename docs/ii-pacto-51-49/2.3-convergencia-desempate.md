## 🜂 Principio

Cuando humano e IA **no convergen**, hay un protocolo claro y ceremonial para resolver.

## 🜄 Reglas de Desempate

| Escenario | Regla | Resolución |
|-----------|-------|-----------|
| Humano + IA convergen | Firma doble | Aprobado |
| Humano propone A, IA propone B | Veto humano | Humano decide |
| IA dividida (2-2-1) | Quórum 4/5 no alcanzado | Rechazado |
| Humano ausente + IA dividida | HALT | Esperar humano |
| Humano vetado + IA aprueba | Veto gana | Rechazado |

## 🜁 Implementación

```javascript
// src/consensus/desempate.js (conceptual)
export function desempatar({ propuesta_humano, propuesta_ia, veto_humano }) {
  if (veto_humano) {
    return {
      ganador: 'humano',
      propuesta: propuesta_humano,
      razon: 'Veto humano ejercido (51%)',
      sellado: '◯_● · 51/49/100',
    };
  }
  if (!propuesta_ia || propuesta_ia.length === 0) {
    return {
      ganador: 'humano',
      propuesta: propuesta_humano,
      razon: 'Sin contrapropuesta IA',
      sellado: '◯_● · 51/49/100',
    };
  }
  // Convergencia
  if (propuesta_humano === propuesta_ia) {
    return {
      ganador: 'ambos',
      propuesta: propuesta_humano,
      razon: 'Convergencia · firma doble',
      sellado: '◯_● · 51/49/100',
    };
  }
  return {
    ganador: 'humano',
    propuesta: propuesta_humano,
    razon: 'Discrepancia · humano decide',
    sellado: '◯_● · 51/49/100',
  };
}
```
