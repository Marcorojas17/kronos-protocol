🚀 Tutorial 01 · Primeros Pasos

🜂 Requisitos

  • Node.js >= 20
  • Git
  • Un editor de texto

🜃 Pasos

1 · Clonar

git clone https://github.com/marcojas17/kronos-protocol.git
cd kronos-protocol

2 · Instalar

make install

3 · Verificar Índice Cero

kronos verify --chain genesis

4 · Servidor MCP

cd marco.mcp
npm install
npm run build
node dist/index.js

5 · Ver la web

Abrir index.html en navegador.
