## 🜄 Casos de Aplicación

| Conflicto | Resolución |
|-----------|-----------|
| TOS de plataforma vs LGU | LGU gana (si TOS no viola ley) |
| Copyright tradicional vs LGU | LGU complementa, no reemplaza |
| Ley nacional vs LGU | Ley gana (derecho público) |
| Licencia open source vs LGU | LGU prevalece si código es núcleo |
| Marca registrada vs LGU | Prevalencia de marca si uso comercial |

## 🜁 Implementación

```javascript
// Resolución de conflictos de licencia
function resolverLicencia(contexto) {
  if (contexto.violaLeyPublica) return 'ley-publica';
  if (contexto.esNucleoArkhe) return 'LGU';
  if (contexto.esKintsugi) return 'LICENSE-KINTSUGI';
  if (contexto.esCodigo) return 'LICENSE';
  if (contexto.esContenido) return 'LICENSE-CONTENT';
  if (contexto.esAuxiliar) return 'LICENSE-MIT';
  return 'terceros';
}
```
