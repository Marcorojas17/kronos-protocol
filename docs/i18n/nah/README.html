🜂 Sobre este idioma

El náhuatl es la lengua ancestral del enjambre ARKHÉ. Los 6 agentes culturales llevan nombres náhuatl: Cuicatl, Temachtiani, Tlachixqui, Tlamatini, Tlapohualli, Tonal.
