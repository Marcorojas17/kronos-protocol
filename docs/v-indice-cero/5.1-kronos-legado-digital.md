## 🜂 Concepto

**Kronos** es el framework de verificación criptográfica de ARKHÉ ZERO. Permite probar 3 cosas sin permiso:

1. Que un documento **existía** en una fecha
2. Quién lo **firmó** (humano + IA)
3. Que **no ha sido alterado**

## 🜁 Uso

```javascript
import { sign, verify } from './crypto/operations/sign.js';

// Firmar
const { firma, hash } = await sign({
  contenido: 'Mi obra',
  alg: 'Ed25519+ML-DSA-87',
  secretKey: myKeys,
});

// Verificar
const { valido, veredicto } = await verify({
  contenido: 'Mi obra',
  firma,
  publicKey: myPublicKey,
  alg: 'Ed25519+ML-DSA-87',
  hashEsperado: hash,
});

console.log(veredicto);
// 'DOCUMENTO ÍNTEGRO · ANCLADO AL ÍNDICE CERO'
```
