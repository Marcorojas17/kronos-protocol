## 🜂 Concepto

Una **cápsula de memoria** es un paquete autocontenido que puede reconstruirse en el futuro sin depender de ARKHÉ ZERO.

## 🜃 Estructura de una cápsula

```javascript
{
  id: "cap-f03f7e2d8526",
  contexto: "Aprobación del Sub-bloque E · Contexto IA",
  decision: "Sellar 13 archivos con hash SHA3-512",
  autor: "Marco Antonio Rojas Valdovinos",
  hash: "f03f7e2d852617309457e0fe207f8f8bd...",
  anclaje: "arkhe://genesis/000-INDICE-CERO-KRONOS",
  reconstruible: true,
  sellado: "◯_● · 51/49/100",
  timestamp: "2026-01-01T00:00:00Z"
}
```

## 🜄 Uso

```bash
┌─(kali㉿arkhe-zero)-[~/docs]
└─$ node -e "
  import('./src/memory/capsulas.js').then(m => {
```
