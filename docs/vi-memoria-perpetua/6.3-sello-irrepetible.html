🜂 Concepto

Cada cápsula sellada con ◯_● es única en el universo. No hay dos cápsulas con el mismo sello + hash.

🜃 Por qué es irrepetible

🜄 Cómo se calcula

import { sha3_512 } from './crypto/primitives/sha3-512.js';

const capsula = {
  contenido: 'Aprobación Sub-bloque E',
  autor: 'Marco Antonio Rojas Valdovinos',
  timestamp: new Date().toISOString(),
};

const sello = '◯_● · 51/49/100';
const hash = sha3_512(JSON.stringify(capsula) + sello);

// hash: f03f7e2d852617309457e0fe207f8f8bd...
// Irrepetible: combina contenido + autor + tiempo + sello
