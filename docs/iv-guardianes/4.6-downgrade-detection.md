## 🜂 Concepto

Un **ataque de downgrade** intenta convencer al sistema de usar algoritmos débiles. El centinela lo detecta y bloquea.

## 🜃 Algoritmos Prohibidos

```javascript
export const ALGORITMOS_PROHIBIDOS = [
  'md5', 'sha1', 'sha-1',
  'rsa-1024', 'rsa1024',
  'des', '3des', 'rc4',
  'ecdsa-p192',
];
```

## 🜄 Detección

```javascript
import { auditarSuite } from './crypto/downgrade-detector.js';

auditarSuite(['sha3-512', 'md5', 'ml-dsa-87']);
// {
//   ok: false,
//   alerta: '🚨 DOWNGRADE DETECTADO · algoritmos prohibidos: md5',
//   permitidos: ['sha3-512', 'ml-dsa-87'],
//   prohibidos: ['md5'],
//   sellado: '◯_● · 51/49/100',
// }

auditarSuite(['sha3-512', 'ml-dsa-87', 'ml-kem-1024']);
```
