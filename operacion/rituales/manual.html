Manual de Usuario

¿Qué hace este módulo?

Define tres rituales canónicos (diario, semanal, mensual) y permite ejecutarlos, registrarlos con notas y firmarlos con Ed25519.

¿Cómo se usa?

  • Ejecuta primero todos los módulos previos.
  • Abre operacion/rituales/index.html.
  • Escribe la contraseña maestra.
  • Toca "Cargar rituales".
  • Verás los 3 rituales y su estado (al día o vencido).
  • Toca "Ejecutar ritual" en el que toque.
  • Escribe notas y firma.

Los 3 rituales

  • Diario: revisar dashboard + integridad (5 min).
  • Semanal: backup cifrado + copia externa (15 min).
  • Mensual: anclaje Merkle a Ethereum (30 min).

Manual de Admin

Integración

import { Rituales } from './rituales.js';

const rituales = new Rituales(core, storage, bus);

const estado = await rituales.estado(humano);
// estado.rituales · estado.historial

const registro = await rituales.ejecutar(
  'diario',
  'Revisé dashboard. Cadena íntegra.',
  'optimo',
  humano
);

const ok = await rituales.verificar(registro);
const blob = await rituales.exportar();

Añadir un ritual nuevo

Edita el array RITUALES en rituales.js. Cada ritual requiere id, nombre, descripción y frecuencia_ms.

Cálculo de caducidad

La próxima fecha = última ejecución + frecuencia. Si no hay ejecución previa, se considera vencido desde el inicio.

Manual de Seguridad

Modelo de amenazas

  • Ejecución alterada: el payload_hash lo detecta.
  • Suplantación del firmante: requiere la clave privada Ed25519.
  • Falsas ejecuciones: solo se firman con identidad humana real.

Parámetros criptográficos

  • SHA-256 para hash del payload canónico.
  • Ed25519 para firma del humano.
  • AES-GCM-256 heredado para persistencia cifrada.

Limitaciones honestas

  • Los rituales son disciplina personal: no hay recordatorios automáticos por notificaciones del sistema operativo. El humano debe auto-disciplinarse.
  • No hay verificación cruzada con el dashboard: si el humano marca "óptimo" sin revisar, no hay sanción. La integridad del sistema depende de la honestidad del fundador.
  • No hay bloqueo por rituales vencidos: el ecosistema sigue funcionando aunque el humano no los ejecute.
