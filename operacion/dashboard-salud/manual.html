Manual de Usuario

¿Qué hace este módulo?

Muestra el estado del ecosistema: módulos registrados, registros persistidos, eventos, evidencias, integridad de cadena y salud global. Incluye radar visual de 5 dimensiones.

¿Cómo se usa?

  • Ejecuta primero 2.1, 2.2, 2.3, 3.1, 3.2, 4.1 y 4.2.
  • Abre operacion/dashboard-salud/index.html.
  • Escribe la contraseña maestra.
  • Toca "Cargar dashboard".
  • Lee métricas, radar y estado por módulo.
  • Exporta el reporte si necesitas archivarlo.

Interpretación de colores

  • 🟢 ÓPTIMO: salud ≥ 90%.
  • 🟡 ESTABLE: salud 70-89%.
  • 🔴 ATENCIÓN: salud < 70%.

Manual de Admin

Integración

import { DashboardSalud } from './dashboard.js';

const dashboard = new DashboardSalud(core, storage, bus, router);
const reporte = await dashboard.generar(humano);

Estructura del reporte

  • metricas · módulos, registros, eventos, evidencias.
  • integridad · estado de la cadena del Cripto Core.
  • dimensiones · 5 dimensiones del radar.
  • modulos · estado individual de cada uno.
  • salud_global · puntuación 0–100.

Cálculo de salud

Cada dimensión puntúa de 50 a 100 según el porcentaje de módulos activos. La salud global es el promedio simple de las 5 dimensiones.

Manual de Seguridad

Modelo de amenazas

  • Lectura sin contraseña: el dashboard no carga sin descifrar Storage Dexie.
  • Reporte alterado: la exportación no va firmada en esta versión (futura mejora).
  • Fuga de métricas: no hay red; el reporte vive solo en tu navegador.

Parámetros

  • Cálculo local, sin red.
  • Hash SHA-256 del Cripto Core para integridad.
  • Las métricas son agregadas, no exponen contenido.

Limitaciones honestas

  • El reporte no va firmado en v1.0. Futura versión incluirá firma Ed25519.
  • La salud global es una aproximación basada en actividad, no un juicio absoluto: un ecosistema con poco uso puede mostrar salud baja aunque no haya problemas.
  • No hay umbral de alerta automatizado: el humano interpreta.
