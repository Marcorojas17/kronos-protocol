## 🜂 Concepto

Cuando una firma cruza fronteras, **¿cuál jurisdicción aplica?** La LGU define un protocolo claro.

## 🜁 Implementación

```javascript
// Resolución de jurisdicción para firma
function resolverJurisdiccion({ firmante, receptor }) {
  const jFirmante = jurisdiccionPrimaria(firmante);
  const jReceptor = jurisdiccionPrimaria(receptor);

  if (jFirmante === jReceptor) {
    return { modo: 'local', jurisdiccion: jFirmante };
  }

  return {
    modo: 'transfronterizo',
    jurisdicciones: [jFirmante, jReceptor],
    protocolo: 'doble-sello + ethereum',
    arbitraje: 'quorum-4-5 + veto-humano',
    sellado: '◯_● · 51/49/100',
  };
}
```
