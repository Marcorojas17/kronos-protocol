## 🜂 Principio

Las **Métricas de Atracción** miden el impacto del movimiento
**sin violar la privacidad de nadie**.

```diff
+ Privacy-First · sin cookies, sin tracking, sin fingerprinting
+ Local-First   · datos agregados viven en el navegador
+ Open Data     · métricas agregadas son públicas
+ Verificable   · todo dato tiene hash
- NUNCA vender datos
- NUNCA rastrear usuarios individuales
- NUNCA usar Google Analytics
- NUNCA compartir con terceros
```
