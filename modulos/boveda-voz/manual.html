Manual de Usuario

¿Qué hace este módulo?

Graba audio desde tu micrófono, calcula su hash SHA-256, genera una huella cimática visual a partir del espectro de frecuencias, y sella todo como paquete .evidence alineado a ISO/IEC 27037.

¿Cómo se usa?

  • Ejecuta primero 2.1, 2.2, 2.3 y 3.1.
  • Abre modulos/boveda-voz/index.html.
  • Escribe la contraseña maestra.
  • Toca "Iniciar grabación" y permite el acceso al micrófono.
  • Habla con claridad. Toca "Detener" al terminar.
  • Revisa el audio. Añade declaración y toca "Sellar".
  • Descarga audio, huella PNG y paquete .evidence.

¿Qué evitar?

  • No grabes audio sin consentimiento del interlocutor.
  • No cierres la pestaña durante la grabación.
  • No compartas el paquete con datos sensibles sin cifrar.

Manual de Admin

Integración

import { BovedaVoz } from './boveda.js';
import { EvidenceOS } from '../evidence-os/evidence.js';

const boveda = new BovedaVoz();
boveda.onWaveform = data => { /* dibujar */ };
await boveda.iniciar();
const { blob, buffer, duracionSeg, frecuenciaPromedio } = await boveda.detener();
const cymatic = boveda.dibujarCimatico(canvas, frecuenciaPromedio);

const evidence = new EvidenceOS(core, storage);
const paquete = await evidence.sellar({ ... });

Parámetros de grabación

  • Formato: audio/webm;codecs=opus cuando está disponible.
  • Chunks de 250 ms para streaming progresivo.
  • FFT size: 2048 para resolución espectral media-alta.
  • Sin echo cancellation ni noise suppression (forense).

Composición del hash

El hash se calcula sobre audio_bytes || cymatic_data_url, es decir, el certificado cubre tanto el audio como su huella visual, evitando sustitución independiente.

Manual de Seguridad

Modelo de amenazas

  • Alteración del audio: cualquier cambio invalida el hash SHA-256.
  • Sustitución de huella: el hash cubre también el PNG cimático.
  • Deepfake de voz: el módulo no verifica autenticidad vocal (ver limitaciones).
  • Suplantación de firmante: requiere clave privada Ed25519 del humano.

Parámetros criptográficos

  • SHA-256 sobre audio || cymatic.
  • HMAC-SHA256 heredado de Evidence OS.
  • Ed25519 para firma del humano.
  • Sello temporal NOM-151 heredado.

Limitaciones honestas

  • Este módulo prueba integridad y existencia, no autenticidad vocal. La detección de voz sintética o clonada requeriría un módulo adicional de análisis forense de audio.
  • La huella cimática es derivada del espectro, no una grabación del campo sonoro. Es una representación visual verificable, no una prueba física de cimática real.
  • El acceso al micrófono requiere HTTPS. En GitHub Pages funciona correctamente; en HTTP local puede fallar.
  • No hay validación de originalidad: prueba que el audio existía al momento del sellado, no que fuera original o no editado previamente.
  • Este módulo NO reemplaza a un peritaje forense profesional en juicio.
