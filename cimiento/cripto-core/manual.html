Manual de Usuario

¿Qué hace este módulo?

Demuestra el núcleo criptográfico: cifra, firma, persiste en IndexedDB y verifica la integridad de la cadena.

¿Cómo se usa?

  • Abre cimiento/cripto-core/index.html.
  • Escribe una contraseña maestra (mín. 8 caracteres).
  • Escribe el texto que quieres cifrar.
  • Toca "Cifrar + firmar + persistir".
  • Recarga la página y toca "Recuperar de IndexedDB" para descifrar.
  • Toca "Verificar cadena" para comprobar integridad.

¿Qué evitar?

  • No olvides la contraseña: sin ella, los datos son ilegibles.
  • No uses este demo con datos reales sensibles todavía (es infraestructura).

Manual de Admin

Integración en módulos superiores

Importa CriptoCore desde core.js:

import { CriptoCore } from '../cimiento/cripto-core/core.js';
const core = new CriptoCore();
await core.init(password);
await core.guardar({ tipo: 'x', payload: {...} });

Parámetros por defecto

  • PBKDF2 · SHA-256 · 600,000 iteraciones · salt 32B.
  • AES-GCM · 256 bits · IV 12B random por bloque.
  • Ed25519 · par persistente en localStorage.
  • IndexedDB: base legado_cripto_core · store cadena.

Backup

Exporta el contenido de IndexedDB con herramientas del navegador (DevTools → Application → IndexedDB). El certificado completo de cada bloque incluye cipher + iv + hash + firma.

Manual de Seguridad

Modelo de amenazas

  • Robo del dispositivo: los datos están cifrados con tu contraseña.
  • Alteración de IndexedDB: el hash chain detecta cualquier cambio.
  • Falsificación de bloques: la firma Ed25519 es infalsificable sin la clave privada.
  • MITM: no hay red, todo es local.

Parámetros criptográficos

  • PBKDF2 con 600k iteraciones (alineado a OWASP 2024).
  • AES-GCM-256 con IV único por operación.
  • Ed25519 para firma digital de cada bloque.
  • SHA-256 para hash chain.

Limitaciones honestas

  • No hay anclaje blockchain todavía (módulo 1.3 lo hará).
  • La clave privada se guarda en localStorage: un XSS exitoso podría robarla. CSP estricta mitiga esto.
  • Este módulo no reemplaza una auditoría profesional antes de usarse con datos reales sensibles.
