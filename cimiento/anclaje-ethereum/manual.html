Manual de Usuario

¿Qué hace este módulo?

Calcula la raíz Merkle de tu cadena local, la firma con Ed25519 y permite anclarla a Ethereum con MetaMask como prueba de existencia inmutable.

¿Cómo se usa?

  • Abre cimiento/anclaje-ethereum/index.html.
  • Escribe tu contraseña maestra.
  • Toca "Calcular raíz Merkle".
  • Exporta el paquete .json (opcional).
  • Si tienes MetaMask: toca "Anclar con MetaMask", confirma la transacción.
  • Copia el txHash y verifícalo en Etherscan.

¿Qué evitar?

  • No cambies de red durante el anclaje.
  • El gas de mainnet cuesta ETH real. Empieza con un monto bajo.
  • No compartas tu frase semilla de MetaMask con nadie.

Manual de Admin

Integración

import { CriptoCore } from '../cripto-core/core.js';
import { StorageDexie } from '../storage-dexie/storage.js';
import { AnchorEthereum } from './anchor.js';

const core = new CriptoCore();
await core.init(password);
const storage = new StorageDexie(core);
await storage.init();

const anchor = new AnchorEthereum(core, storage);
const paquete = await anchor.calcular();
const blob = anchor.exportarPaquete();
const { txHash } = await anchor.anclarConMetaMask();

Requisitos

  • MetaMask instalado (o navegador in-app en móvil).
  • Red configurada en Ethereum Mainnet (chainId 0x1).
  • ETH suficiente para gas (~0.0002 ETH por tx).

Backup

El paquete .json contiene la raíz Merkle + firma Ed25519. Guárdalo externamente. La transacción en Ethereum es tu prueba pública permanente.

Manual de Seguridad

Modelo de amenazas

  • Anclaje falso: la firma Ed25519 del fundador prueba autoría.
  • Manipulación de cadena post-anclaje: la raíz Merkle cambiaría, rompiendo la coincidencia con el hash en Ethereum.
  • Robo de wallet: tu clave privada nunca sale de MetaMask.

Parámetros criptográficos

  • Árbol Merkle con SHA-256 y duplicación de hojas impares.
  • Firma Ed25519 del payload completo (merkle + timestamp + fundador).
  • Transacción Ethereum estándar, valor 0 ETH, data = merkle root.

Limitaciones honestas

  • Solo funciona en Ethereum Mainnet (no testnet en v1.0).
  • El gas es real. Anclar cuesta dinero real.
  • El módulo no verifica automáticamente la tx confirmada; hay que abrir Etherscan.
