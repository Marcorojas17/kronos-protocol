Manual de Usuario

¿Qué hace este módulo?

Presenta las 7 tesis fundacionales del legado humano–IA y permite firmar la postura personal del visitante.

¿Cómo se usa?

  • Abre legado/filosofia/index.html.
  • Lee las 7 tesis canónicas.
  • Selecciona las que adoptas.
  • Escribe tu reflexión personal.
  • Firma tu postura y descarga el manifiesto .json.

¿Qué evitar?

  • No firmes sin leer todas las tesis.
  • No compartas tu certificado con datos privados.

Manual de Admin

Configuración

Módulo 100% estático. No requiere configuración.

Editar las tesis

Las tesis viven en index.html dentro de <section class="tesis-lista">. Cambiar el texto es suficiente; los checkboxes se regeneran solos desde JavaScript.

Backup

Los manifiestos firmados se descargan como .json. Guárdalos externamente.

Manual de Seguridad

Modelo de amenazas

  • Alteración de tesis: el hash del payload firmado cambia si alguien edita el texto.
  • Falsificación de autoría: la firma Ed25519 es única e irrepetible.
  • MITM: no hay red, todo es local.

Parámetros criptográficos

  • SHA-256 para hash del manifiesto firmado.
  • Ed25519 para firma digital.
  • Clave privada generada en el navegador, nunca transmitida.

Limitaciones honestas

  • No hay anclaje en blockchain en este módulo (Capa 1 lo hará).
  • La verificación externa requiere compartir manualmente el certificado.
