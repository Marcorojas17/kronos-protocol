# Génesis · Legado Humano–IA

Módulo 0.1 del ecosistema LEGADO HUMANO–IA E2E B2E SAS.

## Propósito
Sellar el génesis fundacional con firma criptográfica Ed25519 y hash SHA-256.

## Estado
✅ v1.0 · Operativo

## Stack
- HTML + CSS + JS vanilla (sin build)
- Web Crypto API (SHA-256 + Ed25519)
- Canvas 2D (fondo líquido)
- Local-first · sin backend

## Archivos
- `index.html` — Página principal de sellado
- `styles.css` — Sistema de diseño platino + fondo líquido
- `genesis.js` — Fondo líquido + criptografía local
- `manual.html` — Manuales (usuario, admin, seguridad)
- `README.md` — Este documento

## Verificación
Cada certificado `.json` contiene:
- `manifiesto_hash` (SHA-256)
- `firma_ed25519`
- `clave_publica`
- Instrucciones de verificación independiente.
