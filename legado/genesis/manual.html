Manual de Usuario

¿Qué hace este módulo?

Sella tu génesis fundacional: un registro criptográfico inmutable de tu intención, firmado con Ed25519 y hasheado con SHA-256.

¿Cómo se usa?

  • Abre legado/genesis/index.html en tu navegador.
  • Escribe tu nombre y tu intención fundacional.
  • Elige la co-autoría IA (o "Ninguna").
  • Toca "Sellar génesis".
  • Descarga el certificado .json.

¿Qué evitar?

  • No uses navegadores antiguos (sin Web Crypto).
  • No compartas tu certificado si contiene datos privados.
  • No cierres la pestaña antes de descargar el certificado.

Manual de Admin

Configuración

No requiere configuración. El módulo es 100% estático.

BYOK (IA)

Si quieres conectar una IA real (OpenAI, Anthropic, OpenRouter), añade tu API Key en el futuro módulo legado/identidad. Por ahora, la co-autoría es declarativa.

Backup

  • El certificado .json es tu respaldo. Guárdalo.
  • El borrador se guarda en localStorage. No hay sync remoto.

Crisis

  • Si el certificado se pierde: vuelve a sellar (pero el hash será distinto).
  • Si el navegador no soporta Ed25519: actualiza o cambia de navegador.

Manual de Seguridad

Modelo de amenazas

  • Plagio: el hash prueba autoría y fecha del manifiesto.
  • Alteración: cualquier cambio rompe el hash y la firma.
  • Man-in-the-middle: no hay red, no hay MITM.

Parámetros criptográficos

  • SHA-256 para hash del manifiesto.
  • Ed25519 para firma digital.
  • Clave privada generada localmente, nunca transmitida.

Limitaciones honestas

  • No garantizamos anclaje en blockchain en este módulo (se hará en la Capa 1).
  • El certificado es local; la verificación por terceros requiere compartirlo manualmente.
  • Este módulo no es inmune a un atacante con acceso físico a tu dispositivo.
