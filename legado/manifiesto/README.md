# Manifiesto · Legado Humano–IA

Módulo 0.4 · cierre de la Capa 0 (Génesis).

## Propósito
Unificar Génesis + Filosofía + Autoría en un manifiesto navegable, exportable y firmable.

## Estado
✅ v1.0 · Operativo

## Stack
- HTML + CSS + JS vanilla
- Web Crypto API (SHA-256 + Ed25519)
- Canvas 2D (fondo líquido unificado)
- Local-first · sin backend

## Archivos
- `index.html` — Manifiesto navegable + firma de testigo
- `styles.css` — Sistema de diseño platino + índice de capas
- `manifiesto.js` — Fondo líquido + cripto + exportación
- `manual.html` — Manuales (usuario, admin, seguridad)
- `README.md` — Este documento

## Estructura del manifiesto
1. **Génesis** — Acta fundacional + Safe Creative + anclaje Ethereum
2. **Filosofía** — Las 7 tesis canónicas
3. **Autoría** — Humano + IA · Atribución reforzada Proyectos 49 y 51
4. **Cierre** — Firma del testigo
