Manual de Usuario

¿Qué hace este módulo?

Unifica Génesis, Filosofía y Autoría en un manifiesto navegable. Permite exportarlo y firmarlo como testigo.

¿Cómo se usa?

  • Abre legado/manifiesto/index.html.
  • Recorre las 4 secciones: Génesis, Filosofía, Autoría, Cierre.
  • Exporta el manifiesto en .md.
  • Firma como testigo al final.
  • Descarga tu certificado .json.

¿Qué evitar?

  • No firmes sin leer las 4 secciones.
  • No compartas tu certificado con datos privados.

Manual de Admin

Editar secciones

Cada sección vive en index.html con su id (#genesis, #filosofia, #autoria, #cierre). Modificar texto no requiere cambios en JS.

Actualizar el manifiesto exportable

La constante MANIFIESTO_MD en manifiesto.js contiene el texto que se exporta. Si editas el HTML, actualiza también esta constante para mantener coherencia.

Backup

Cada certificado de testigo se descarga como .json. Guardar externamente.

Manual de Seguridad

Modelo de amenazas

  • Alteración del manifiesto: el hash del payload cambia si alguien edita el texto firmado.
  • Falsificación de testigos: cada firma Ed25519 es única.
  • MITM: no hay red, todo es local.

Parámetros criptográficos

  • SHA-256 para hash del payload de firma.
  • Ed25519 para firma digital.
  • Clave privada generada localmente, nunca transmitida.

Limitaciones honestas

  • El manifiesto exportado no incluye firma automática del autor. Se firma como testigo aparte.
  • La verificación externa requiere compartir manualmente el certificado.
