## 🧠 ¿Qué es `marco.mcp`?

Servidor **Model Context Protocol** local que expone tu identidad,
proyectos, decisiones y voz a cualquier IA compatible (Claude, Gemini,
Cursor, Copilot, Codex, LLMs locales).

## ⚙️ Instalación rápida

```bash
cd marco.mcp
npm install
cp .env.example .env
npm run build
node dist/index.js
```
